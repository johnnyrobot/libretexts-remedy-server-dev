# Historical bootstrap corpus

This directory is retained as historical evidence. Its 50 source artifacts are
invalid placeholders with automated bootstrap attribution. Matching hashes,
stored scores and the historical `human_verified` / `human_specialist` labels
do not qualify it as human-reviewed or calibrated evidence. Current calibration
readiness intentionally refuses it. Annotation/schema coverage and stored
snapshot checks are mechanical checks, not specialist-review certification.

Keep these files unchanged. Use a new corpus version for real attributable
evidence and follow [the operator evidence requirements](../../../deploy/calibration-evidence.md).
